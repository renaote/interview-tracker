# User stories — Interview & Internship Prep Tracker

Format: As a `<role>`, I want `<goal>`, so that `<benefit>`.

## Core tracking
1. As an applicant, I want to add a company and the role I applied for, so that I keep everything in one place instead of a messy spreadsheet.
2. As an applicant, I want to set what stage I'm at (Applied, Assessment, Interview, Offer, Rejected), so that I know where I stand without having to remember.
3. As an applicant, I want to move an application to the next stage with one click, so that updating it is fast and I don't lose my train of thought.
4. As an applicant, I want to set a deadline for each application, so that I don't miss an assessment or interview.
5. As an applicant, I want anything due in the next 3 days to stand out, so that I notice urgent stuff without checking every date myself.
6. As an applicant, I want to write free notes on each application, so that I remember things like interviewer names or questions they asked.

## Search & filter
7. As an applicant, I want to search by company name or role, so that I can find one quickly once the list gets long.
8. As an applicant, I want to filter by stage, so that I can see just the ones waiting on an interview, for example.

## Dashboard
9. As an applicant, I want to see how many applications are at each stage, so that I get a quick sense of how my job search is going overall.

## Data management
10. As an applicant, I want to edit an application's details, so that I can fix mistakes or update it as things change.
11. As an applicant, I want to delete an application, so that my list doesn't get cluttered with stuff I no longer care about.
12. As an applicant, I want my data saved locally, so that it's still there next time I open the app, no login needed.

## Out of scope (v1)
- Multiple user accounts / syncing to the cloud
- Connecting to email or a calendar
- Storing resumes or cover letters
